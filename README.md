# Uthram Stores website

A mobile-friendly website for Uthram Stores, a neighbourhood grocery store at Meghamalhar Complex, Akkarapuram, Thrissur. Built as the final project for the IIM Bangalore Website Development course, with the owner's permission.

**Live site:** https://YOUR-USERNAME.github.io/uthram-stores/

## What it does
- Shows opening hours, delivery area and an "Open now / Closed now" status
- Categorised product list with photos, search, and In stock / Out of stock tags
- Order list builder that sends the customer's list to the store on WhatsApp
- Festive Onam and Vishu pack enquiries, Google Map, phone and email

## Built with
HTML, CSS and vanilla JavaScript in a single `index.html`, with product photos in `images/`. No frameworks or build step. Hosted on GitHub Pages.

## Updating the shop
Open `index.html` and edit the `PRODUCTS` list in the script:
- `p` is the price in rupees (leave `null` to show "Ask for price")
- `s` is `true` for In stock and `false` for Out of stock
- `i` is the photo file name in `images/` (leave empty for a letter tile)
